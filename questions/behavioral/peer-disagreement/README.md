# Peer Disagreement

**Category:** Behavioral
**Difficulty:** medium
**Suggested Time:** ~8 minutes
**Competency:** conflict

---

Tell me about a time you disagreed with a peer about a technical approach and had to work it out together, without pulling in a manager to settle it.

I want to know how you handled the disagreement itself — walk me through what each of you actually said, not just how it turned out.
