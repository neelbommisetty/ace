# Probe Bank

Follow-up questions to pull from when drilling into this story. Hidden
until the debrief — this file is a dotfile precisely so it stays invisible
before then.

1. What exactly did the person say — can you get close to their actual words?
2. What was your honest first reaction, before you had time to process it?
3. What's one concrete thing you did differently afterward that you could point to?
4. Did you go back to that person later? What did that conversation look like?
